## 📂 项目结构

```

├── index.html      # 学习追踪网站（单文件，可直接打开）
```

## 🛠 本地使用

直接用浏览器打开 `index.html` 即可：
```bash
open index.html
# 或启动一个本地服务器
python3 -m http.server 8888
# 访问 http://localhost:8888
```
